# Simple Messaging Application (Procedural PHP)

A classic early-2000s style messaging application built with procedural PHP, SQLite, and Bootstrap 5.

## Features
- User registration and login system
- Send direct messages to other users
- Create and join group chats
- View message history
- Simple session-based authentication

## Requirements
- PHP 7.4 or higher (with SQLite support enabled)
- A web server (Apache, Nginx, or PHP's built-in server)
- Modern web browser

## Installation Steps

1. **Extract all files** to a single folder (e.g., `messaging-app/`)

2. **Run the setup script** to create the database:
   - Open your browser and navigate to: `http://localhost/messaging-app/setup.php`
   - You should see "Database setup complete!"

3. **Start using the application**:
   - Navigate to: `http://localhost/messaging-app/index.php`
   - Create a new account or login

4. **Default test accounts** (created by setup.php):

   - Username: `jane` / Password: `password123`
